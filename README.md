# Movie RecSys

RecSys of movies based on dataset MovieLens 100K.

SVD collaborative filtering + FastAPI + Streamlit + Docker.

## Stack

- Python 3.14
- pandas, numpy, scikit-learn
- scikit-surprise (SVD)
- FastAPI + Pydantic
- Streamlit
- Docker + Docker Compose
- pytest
